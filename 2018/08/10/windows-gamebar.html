Windows 10 Game Bar

Updating the Windows 10 Game Bar for the Fluent Design System, modernizing its visual language while introducing performance insights and a new Game Mode for PC gamers.

The Windows 10 Game Bar was a native overlay that gave players quick access to system and Xbox features while gaming. When I joined the project as a Visual Designer, the product was transitioning from a minimal utility into a fuller gaming hub. My task was to bring its design into alignment with the evolving Fluent Design System while introducing a new feature set focused on performance visualization and Game Mode, which optimized PC resources for gaming.

Problem

The original Game Bar design lacked a cohesive identity. It was functional but visually inconsistent with the Windows 10 ecosystem and didn’t feel premium enough for PC gamers. As new features like Game Mode and performance telemetry were added, the interface risked becoming cluttered and confusing without a clear visual hierarchy or brand direction.

Design Process

To align with Fluent Design principles, I focused on:

Depth and Materiality
Introduced acrylic layers, subtle lighting, and contrast to make the overlay feel grounded yet unobtrusive over gameplay.
Information Clarity
Designed real-time CPU/GPU/RAM visualizations that conveyed performance impact at a glance without overwhelming players.
Contextual Adaptation
Ensured accessibility and legibility across light/dark system themes and high-motion gameplay backgrounds.

Privacy-First Clip Capture

“Save last 30 seconds” is off by default and only activates after an intentional user toggle.

Built For Streamers

Mixer integration makes it easier for streamers to start broadcasting at a click.

Outcome & Impact

The updated Windows 10 Game Bar delivered a clearer, more trustworthy, and more polished gaming overlay that aligned with Fluent Design and set the foundation for future Xbox Game Bar improvements.

Stronger Trust & Adoption
Opt-in recording, visible status, and easy controls reduced apprehension and encouraged sharing.
Clearer Performance Feedback
Players understood when Game Mode helped and how their system was behaving mid-match.
Ease of Use
Provided the basic features that many PC gamers needed in the native OS.
