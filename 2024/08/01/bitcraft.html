Context

BitCraft Online is a sandbox MMO built around player-driven worldbuilding: exploration, survival, crafting, and a persistent open world shaped by its community. Designing UI for a game at this scale means solving for information density first. Players are managing inventory, tracking progression, coordinating with others, and interacting with simulation systems simultaneously. The interface cannot afford to be slow, cluttered, or inconsistent. The starting point was establishing a visual identity strong enough to unify every surface, then building the component system to deliver it across the full game.

Visual Identity

The foundation of BitCraft's visual language is an art deco-inspired design system built for density and clarity:

Color Palette
The palette uses a split complementary system, two colors flanking the complementary of the primary, creating visual harmony without monotony. Each primary has tonal variants for layering, segmentation, and subtle UI patterning. A light and dark mode support both casual and low-light play sessions.
Typography & Spacing
The type ramp is built on a 14px base with an augmented fourth scale (1.414), calibrated for information-dense interfaces where hierarchy needs to be legible without oversized headers competing with game data. An 8pt spacing grid brings rhythm to component layout and padding throughout.
Shape Language
The visual language draws from art deco geometry: precise angles, intersecting lines at 45 and 30 degrees, and a strict use of 4px and 8px stroke weights for dividers and framing elements. This gives the interface a structural consistency that reads as crafted rather than generic.

Interface Design

With the visual system defined, every UI surface needed to be built from it. The goal was a component library comprehensive enough to handle the full range of MMO interactions without requiring one-off solutions:

Component Library
Built to cover the full range of MMO interaction contexts, from inventory and crafting to dialogue and progression. Every component draws from the same visual system to keep the interface coherent regardless of context.
Windows & Panels
Modular window and panel system designed to handle dense information loads without visual noise. Built to accommodate the game's layered simulation systems.
HUD
The in-game heads-up display keeps critical information accessible during active play without occluding the game world. Designed to scale with gameplay complexity as players progress.
Notifications & Feedback
A notification system covering both inline and side-panel variants, providing contextual feedback for a world where dozens of concurrent systems are always running.
Cursors & Entities
Contextual cursor states and entity display patterns that communicate interactable objects, NPCs, and player characters at a glance in a populated open world.
