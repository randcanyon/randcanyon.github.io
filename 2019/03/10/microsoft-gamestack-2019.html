Microsoft Game Stack

Microsoft Game Stack was a new brand initiative unifying Microsoft’s tools for game developers across Azure, Xbox, and Visual Studio. I was the visual designer responsible for defining the brand identity and building a cohesive, flexible design system that could scale across digital, marketing, and event touchpoints.

In 2019, Microsoft launched Game Stack to streamline its offering to game developers. The tools existed—but they were scattered across different Microsoft organizations, each with its own visual language. Game Stack aimed to bring these products together under a single umbrella, making it easy for developers to understand how Microsoft supports them from ideation to development, testing, launch, and live operations. As part of the brand team, I led the visual design and styleguide development, creating a unified identity that expressed Microsoft’s developer-friendly values while feeling modern, bold, and relevant to the game industry.

Problem

Game developers often used Microsoft tools: Azure PlayFab, Visual Studio, Xbox Live, Direct, etc. But the ecosystem was fragmented. Each product had its own look and story, resulting in:

Lack of Cohesion
Visual inconsistency across teams and channels.
No Wholistic Story
No central narrative explaining how Microsoft supports end-to-end game development.
Competing Brands
Marketing materials that felt disjointed and lacked a shared brand language.
Hard to Discern
Difficulty for developers to understand what to use and when.

Design Process

Before designing visuals, we defined what Microsoft Game Stack needed to express as a brand. The core values were:

We know games and want to empower you to create worlds.
Game Stack needed to feel like it belonged in the industry — modern, energetic, and visually aligned with the tools developers use every day. The brand should reflect creativity and innovation while still carrying Microsoft’s trust and engineering credibility.
We have the tools for developers from beginning to end.
The brand had to communicate a complete ecosystem — from ideation to live ops. It needed to visually simplify and clarify how all of Microsoft’s technologies (Azure, Xbox, Visual Studio, PlayFab, etc.) work together.
“We support indie teams just as much as AAA studios.”
The visual system couldn’t feel too enterprise or too “big studio.” It needed warmth, approachability, and flexibility — appealing to hobbyists, independent developers, and large game companies alike.
“Our tools are part of one ecosystem that works together throughout your development pipeline.”
This value drives consistency. The identity had to unify products that historically looked and felt disconnected, giving developers a single, coherent experience.

Visual Identity

These four values directly informed the design system from the ground up.

To ground the brand in the aesthetics of game development, we designed a visual system inspired by the RTS (real-time strategy) camera viewpoint.
To represent the full development pipeline, ideation to launch to live operations, we built the brand around a continuous line motif.
The 3D illustration style was intentionally friendly, simplified, and slightly cartoony, creating a visual tone that was inviting for indies, not enterprise-intimidating.
To tie together products across Azure, Xbox, PlayFab, and Visual Studio, we built co-branding directly into the visual language.

Outcome

Microsoft Game Stack launched with a strong, cohesive brand identity that visually unified more than a dozen previously disconnected developer products. The brand system was adopted across:

Microsoft Website
Established a web resource on https://developer.microsoft.com/en-us/games/
Expos and Conferences
Presented at GDC and major gaming conferences
Created a unified Microsoft narrative
For game development, helping developers understand the full ecosystem at a glance.
Strengthened Microsoft’s position
As a partner for game studios by presenting a polished, coherent brand.
